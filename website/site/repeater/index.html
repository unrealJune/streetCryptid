How to set up a repeater

Run a repeater

Open streetcrypt.id/repeater on the computer that will run the repeater, then claim it with this phone.

  1. Install it

    Needs Windows 10 (2004) or Windows 11, x64 or ARM64.

    irm https://streetcrypt.id/repeater/install.ps1 | iex
    powershell -NoProfile -Command "irm https://streetcrypt.id/repeater/install.ps1 | iex"
    x64 installer ARM64 installer

    Most PCs are x64. Snapdragon laptops and Surface Pro X are ARM64.

    This preview isn't signed yet. When Windows says it protected your PC, choose More info, then Run anyway. Read the script first if you want.

  2. Set it up

    • Leave Run as a Windows service on so it runs with nobody signed in. Windows asks for administrator approval once.
    • Turn on Keep awake on mains power. A sleeping PC can't carry anything.
    • Turn off Send diagnostics if you don't want to send them.
    • Press CONTINUE.

  3. Claim it

    • Point your phone's camera at the code on the PC's screen and open the link in streetCryptid.
    • Leave Carry my location on. Turn on Open to anyone only if anyone should be able to ask it to carry their location.
    • Tap CLAIM.

    The code works once and changes every 30 minutes. Don't share a screenshot of it.

  4. Offer it to friends

    When you pair with someone, tap MY REPEATERS and pick this one. They choose whether to use it.

  1. Download the Mac app

    macOS 13 or newer, on Apple Silicon or Intel. One universal download.

    macOS releases

    Choose streetcryptid-repeater-*-universal-macos.zip from a macos-v release, expand it, and move streetCryptid Repeater.app into Applications. If no macOS release is listed, the first signed build is not available yet. Do not disable Gatekeeper or install unsigned CI artifacts.

  2. Choose how it runs

    Open the app and complete setup. Choose Start at login, automatic updates, optional diagnostics, and whether to keep the Mac awake on mains power. Allow its login item in System Settings if macOS asks.

    Closing the window keeps it running in the menu bar. Quit stops it. It runs while you are signed in, not after logout or before login. A sleeping Mac carries nothing; keep-awake does not override closing a laptop lid.

  3. Claim it from your phone

    Scan the app's QR code with your owner phone, or copy the claim link into streetCryptid's Settings → Repeaters. Do not share the one-time code or screenshots of it.

  4. Let it carry

    Status shows encrypted items, traffic and people carried. Manage people from the owner phone. Signed automatic updates keep the same repeater identity and settings.

  1. Download it

    Needs 64-bit Linux, x86_64 or aarch64. A Raspberry Pi 4 or 5 works.

    Latest Linux release

    Check the download against the release's SHA256SUMS before you run it.

    tar xzf streetcryptid-repeater-*-$(uname -m)-linux.tar.gz && cd streetcryptid-repeater-*-$(uname -m)-linux

  2. Run it and claim it

    ./streetcryptid-repeater run
    • Point your phone's camera at the code in the terminal and open the link in streetCryptid.
    • Leave Carry my location on. Turn on Open to anyone only if anyone should be able to ask it to carry their location.
    • Tap CLAIM.

    The code works once and changes every 30 minutes. Don't share a screenshot of it or paste it into a log.

  3. Keep it running

    Stop it with Ctrl-C, then install it as a service that starts at boot:

    sudo ./streetcryptid-repeater install --system
    • Drop sudo and --system to run it only while you're signed in. Add --linger to keep it running after you sign out.
    • Run ./streetcryptid-repeater settings --keep-awake on so the machine doesn't sleep on mains power. Diagnostics stay off unless you add --telemetry on.
    • Run ./streetcryptid-repeater status to see what it's carrying, or ./streetcryptid-repeater claim to show the code again.
    • Put sudo in front of these until you sign out and back in after a --system install.

  4. Offer it to friends

    When you pair with someone, tap MY REPEATERS and pick this one. They choose whether to use it.

Custom relays and diagnostics collector

In Windows or macOS Settings, open Network and collector (Network & collector on Mac). Add iroh relay URLs and an optional access key for each. No custom relays uses the public defaults. Keys stay on the repeater; a blank key keeps the saved one for that URL.

On Linux, streetcryptid-repeater network shows the settings without keys; network --file PATH saves a private JSON file. See the configuration guide for its format. Never put access keys in shell history or screenshots.

The collector URL is an OTLP HTTP base URL. Send diagnostics remains a separate opt-in; use only a collector you trust with diagnostic metadata. Save, then restart the repeater (or its Windows/Linux service) to apply connection changes. Your identity, claim and grants are preserved.
