Run a repeater

A computer that stays on and keeps your sealed location for friends while your phone sleeps. It holds ciphertext only, in memory, and can never read where you are.

You're on a phone. A repeater runs on a computer that stays on: open streetcrypt.id/repeater there, then come back to this phone to claim it.

  1. Install

    Windows 10 (2004) or Windows 11, x64 or ARM64. No administrator rights needed.

    irm https://streetcrypt.id/repeater/install.ps1 | iex
    powershell -NoProfile -Command "irm https://streetcrypt.id/repeater/install.ps1 | iex"
    x64 installer ARM64 installer

    Most PCs are x64. Snapdragon laptops and Surface Pro X are ARM64.

    This is an unsigned preview. Windows will say it protected your PC from an unrecognised app. Choose More info, then Run anyway. The script keeps that warning on purpose rather than slipping past it; read it first if you like.

  2. Set it up

    The app opens to a short setup. Nothing is registered until you press Continue.

    • Run as a Windows service, so it keeps carrying with nobody signed in. Windows asks for administrator approval once.
    • Keep this PC awake on mains power. A sleeping PC carries nothing; on battery it sleeps as usual.
    • Send diagnostics is off unless you leave it on.

  3. Claim it

    The PC now shows a claim code. On your phone, open streetCryptid → Settings → Repeaters → Add a repeater, and point the camera at it. Whoever claims it first owns it.

    The code is single-use and replaced every 30 minutes. Don't post a screenshot of it.

  4. Let it carry

    Turn on Carry my location on your repeaters. When you pair with someone you can offer them your repeaters too, and they choose whether to have theirs carried.

Not on macOS yet

There's no Mac repeater yet. Any Windows or Linux computer that stays on will do in the meantime, and you can claim it from an iPhone.

  1. Download

    Any 64-bit Linux, x86_64 or aarch64 (a Raspberry Pi 4 or 5 will do). One binary; nothing needs root to try it.

    Latest Linux release
    tar xzf streetcryptid-repeater-*-linux.tar.gz && cd streetcryptid-repeater-*-linux

    This is a preview. Check the download against the release's SHA256SUMS before you run it.

  2. Run it and claim it

    ./streetcryptid-repeater run

    The terminal shows a claim code. On your phone, open streetCryptid → Settings → Repeaters → Add a repeater, and point the camera at it. Whoever claims it first owns it.

    The code is single-use and replaced every 30 minutes. Don't post a screenshot of it, or paste it into a log.

  3. Keep it running

    Opt in to a systemd service, for you or for the whole machine from boot:

    sudo ./streetcryptid-repeater install --system
    • Your identity moves into the service, so it is the same repeater you just claimed. Without --system it runs as you, while you are signed in (--linger: after you sign out too).
    • Keep awake and send diagnostics are streetcryptid-repeater settings; diagnostics are off unless you turn them on.
    • streetcryptid-repeater status says what it is carrying; claim shows the code again.

  4. Let it carry

    Turn on Carry my location on your repeaters. When you pair with someone you can offer them your repeaters too, and they choose whether to have theirs carried.

What it keeps

Who it carries, on disk, so a restart comes back carrying the same people. What it carries stays in memory and is gone on restart until their phones sync again.

What it can see

Sealed envelopes and whose trail each one is in. Never a position: it holds no keys that open them, the same as the hosted stash.

Stopping

Remove it in the app and it stops carrying anyone and shows a new claim code. Uninstalling removes the app; its identity is kept unless you delete it.
